# BitterLog 🍫

プログラミングの学びや気づきなどを書き留める開発者向け備忘録アプリです

## 機能
- Markdownでメモを書けるエディタ
- ↑リアルタイムプレビュー
- タグ・カテゴリでメモを整理
- 全文検索・タグ検索
- 画像の貼り付け可能
- ピン留め・お気に入り
- ホワイトモード・ダークモード
- データのエクスポート・インポート

## 使い方

### メモの作成
- ツールバーの「新規メモ」ボタンまたはファイルメニューから作成
- タイトルと本文を入力 (Markdown記法に対応)
- 右側にリアルタイムでプレビューが表示されます

### 閲覧・編集モード
- デフォルトは閲覧モード (プレビューのみ表示)
- 「編集」ボタンでエディタを表示

### タグ・カテゴリ
- タグはメモごとに複数設定可能
- カテゴリで大分類に整理できる

### エクスポート・インポート
- `ファイル` → `エクスポート` でZIPファイルに保存
- `ファイル` → `インポート` でZIPファイルから復元

## データの保存場所
```
C:\Users\ユーザー名\BitterLog\
├── bitterlog.db   # データベース
└── images\        # 画像ファイル
```
